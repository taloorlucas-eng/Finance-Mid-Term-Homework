# Finance-Mid-Term-Homework
Finance Mid-Term Homework
本项目第一部分包含shreve书上的基本二叉树定价，输入期权类型，当前时间点和股价，输出期权价值。
第二部分是关于delta的求解，即对冲比例。
第三部分的扩展则是结合shreve二卷内容，将二叉树进化为CRR二叉树，同时利用BSM定价模型进行求解。
最后，为上面的模块做了清晰的可视化，可视化包含三个板块：
1.随着步数无穷细分，定价逐渐逼近BSM定价。
2.随着时间推进，永久美式期权和一般美式期权的行权临界点差异。
3.对比欧式、美式期权的内在价值，持有价值，时间价值的规律。

另外，还有一份pdf文件，解释BSM定价原理的数学推演。
